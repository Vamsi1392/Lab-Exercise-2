## Aim:

To design a mobile UI/UX prototype for an online shopping application by applying Gestalt principles, UI patterns, and usability guidelines using **Myntra** as the case study.

## Algorithm:

1. Select Myntra as the existing application for the case study.

2. Identify the main user flow: **Home → Product Categories**.

3. Create the required mobile frames using Figma.

4. Design the Home screen with a search bar, promotional section, categories, and recommended products.

5. Design the Product Categories screen with product cards, product images, prices, ratings, filters, and sorting options.

6. Organize related interface elements using the Gestalt principles of proximity, similarity, continuity, and common region.

7. Apply UI/UX guidelines such as consistency, alignment, spacing, contrast, and visual hierarchy.

8. Select suitable typography, icons, colors, and interactive elements for the interface.

9. Connect the Home and Product Categories screens using Figma's Prototype feature.

10. Test the navigation between the screens and verify the user flow.

11. Present the completed mobile UI/UX prototype.
